Khám phá Bootstrap Grid System

Bootstrap giúp xây dựng bố cục trang web linh hoạt, dễ sử dụng và phù hợp với nhiều loại màn hình.

01. Container

Container giúp căn chỉnh và giới hạn chiều rộng nội dung trang web.

02. Row và Column

Row và Column giúp sắp xếp nội dung thành các hàng và cột linh hoạt.

03. Responsive

Giao diện tự điều chỉnh theo chiều rộng màn hình máy tính, máy tính bảng và điện thoại.

04. Navbar

Navbar cung cấp menu điều hướng, bao gồm dropdown và menu thu gọn.
