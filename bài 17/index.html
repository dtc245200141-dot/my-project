Thực Hành Các Cách Nhúng CSS

Phần 1: Sử dụng Inline CSS

Tiêu đề được đổi màu bằng Inline CSS (Đỏ)

Đoạn văn này được thay đổi màu sắc trực tiếp bằng thuộc tính style trong thẻ HTML (Xanh dương).

Phần 2: Sử dụng Internal CSS

Tiêu đề được đổi màu bằng Internal CSS (Tím)

Đoạn văn này được định dạng từ thẻ style nằm trong phần head (Xanh lá).

Phần 3: Sử dụng External CSS

Tiêu đề được đổi màu bằng External CSS (Xanh đậm)

Đoạn văn này được định dạng thông qua liên kết tệp style.css bên ngoài (Cam).
